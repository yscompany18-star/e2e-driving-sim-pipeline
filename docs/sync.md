# 자사 데이터 Sensor 동기화

## 정의

자사 차량의 카메라 모델, 셔터 방식, LiDAR 타이밍, 캘리브레이션을 시뮬레이터 센서 모델과 일치시킵니다.

## 왜 필요한가

수 ms 시간 오프셋이나 왜곡 모델 차이만으로도 복원 품질과 정책 입력이 달라집니다.

## 접근 방법

rolling shutter와 f-theta/fisheye 모델을 지원하는 렌더러(3DGUT, SplatAD)를 쓰고, 3DGS-Calib처럼 렌더링 기반으로 외부파라미터·시간 오프셋을 재추정합니다.

## 평가 방법

재투영 오차, 추정 시간 오프셋(ms), 동기화 전후 PSNR 변화.

## 오픈 이슈 · 다음 단계

자사 rig가 NuRec 공식 지원 rig와 다를 때 품질 차이를 정량화해야 합니다.
