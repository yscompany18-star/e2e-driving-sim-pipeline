# E2E Inference-to-Actuation Latency 동기화

## 정의

센서 입력 → 모델 추론 → 제어 명령 → 구동까지의 실제 지연을 시뮬레이터 스텝에 반영합니다.

## 왜 필요한가

지연을 무시하면 시뮬에서 실제보다 좋은 성능이 나옵니다. 200ms 지연만으로도 closed-loop에서 오류가 누적됩니다.

## 접근 방법

AlpaSim의 인위적 latency 설정, Bench2Drive-Robust의 FIFO 지연 버퍼(fixed/measured 모드), 추론이 스텝을 넘으면 이전 제어 유지.

## 평가 방법

지연 0/100/200/500ms별 지표 저하 곡선.

## 오픈 이슈 · 다음 단계

실측 지연 분포를 어디서 계측해 어떤 형태로 넣을지(고정값 vs 분포) 결정이 필요합니다.
