# E2E Model Comparison 환경

## 정의

공개 E2E 모델과 자사 모델을 같은 인터페이스, 같은 장면, 같은 지표로 비교하는 환경입니다.

## 왜 필요한가

모델마다 입력 센서와 주기가 달라 공정한 비교가 어렵습니다.

## 접근 방법

AlpaSim의 컨테이너 gRPC 정책 인터페이스를 공통 규격으로 쓰고, NAVSIM v2/Bench2Drive 프로토콜로 교차 검증합니다.

## 평가 방법

동일 장면 세트에서 모델별 지표와 순위, 반복 실행 분산.

## 오픈 이슈 · 다음 단계

자사 센서 구성에 맞지 않는 공개 모델은 입력 변환이 필요하며, 그 자체가 성능 차이를 만들 수 있습니다.
