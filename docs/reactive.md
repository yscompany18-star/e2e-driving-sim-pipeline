# Reactive Simulation

## 정의

Ego의 행동에 따라 주변 에이전트가 반응하도록 만드는 시뮬레이션입니다.

## 왜 필요한가

로그 재생 에이전트는 ego가 끼어들어도 반응하지 않아 비현실적인 충돌이나 과도하게 쉬운 상황을 만듭니다.

## 접근 방법

SMART·CAT-K 같은 토큰 기반 traffic 모델로 에이전트를 구동하고, 평가 목적에 따라 world-on-rails(재현성)와 reactive 모드를 전환합니다. 모드 전환 개념은 참고자료 GAIA-4에서 가져왔습니다.

## 평가 방법

WOSAC realism meta score, ego 개입 시 충돌·끼어들기 반응의 자연스러움.
