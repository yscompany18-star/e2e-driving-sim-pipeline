# Static Scene

## 정의

도로, 차선, 건물, 식생 등 시간에 따라 변하지 않는 배경을 복원합니다.

## 왜 필요한가

배경은 모든 프레임에 등장하므로 품질 결함이 정책 입력 전체에 영향을 줍니다.

## 접근 방법

동적 영역을 마스킹한 뒤 배경 Gaussian을 학습하고, 하늘은 별도 환경 모델로 처리합니다. LiDAR 깊이로 기하를 고정합니다.

## 평가 방법

동적 객체 제거 후 배경 잔상, 원거리 영역 선명도, 깊이 오차.

## 오픈 이슈 · 다음 단계

미관측 영역(가려진 차선, 원거리)의 보완은 생성 prior가 필요합니다.
