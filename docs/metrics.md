# Metrics-based Evaluation

## 정의

AlpaSim의 closed-loop 지표(collision, off-road, wrong-lane 등)로 정책을 평가합니다.

## 왜 필요한가

평가 지표가 곧 모델 선택 기준이 되므로, 지표가 실제 안전성을 반영하는지가 중요합니다.

## 접근 방법

AlpaSim처럼 지표 계산을 시뮬 실행과 분리해 재분석이 가능하게 하고, 이진 충돌률 외에 심각도(CCM)를 함께 봅니다.

## 평가 방법

지표 간 상관, 실차 결과와의 순위 일치도.

## 오픈 이슈 · 다음 단계

이진 충돌률은 충돌의 심각도와 책임을 구분하지 못합니다.
