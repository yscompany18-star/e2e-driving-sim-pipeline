# Multi-Agent Simulation

## 정의

여러 에이전트의 상호작용을 동시에 생성·시뮬레이션합니다.

## 왜 필요한가

끼어들기, 양보, 교차로 진입처럼 상호작용이 핵심인 장면을 평가하려면 필요합니다.

## 접근 방법

토큰 기반 next-token 모델(SMART)을 closed-loop 미세조정(CAT-K)이나 RL 미세조정(SMART-R1)으로 강화하고, 결과 궤적을 World Model로 센서 영상화합니다. 행동과 센서를 한 모델로 생성하는 방식은 참고자료 GAIA-4를 참고합니다.

## 평가 방법

WOSAC realism, 충돌·이탈률, 개별 에이전트 제어 정확도.

## 오픈 이슈 · 다음 단계

행동 모델과 센서 생성 모델이 분리되어 있으면 둘 사이의 정합 문제가 생깁니다.
