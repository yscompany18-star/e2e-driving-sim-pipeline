# Scenario Mining

## 정의

대규모 로그에서 희귀·위험 시나리오를 찾아 평가 세트로 만듭니다.

## 왜 필요한가

실제로 일어난 위험 상황은 가장 신뢰도 높은 평가 데이터입니다.

## 접근 방법

RefAV처럼 자연어 질의로 시공간 위치를 찾고, SMc2f처럼 VLM 1차 필터와 궤적 매칭을 결합합니다. 찾은 시나리오는 World Model로 날씨·조명 변형을 만듭니다.

## 평가 방법

HOTA-Temporal, 질의별 정밀도·재현율, 사람 검수 대비 일치율.

## 오픈 이슈 · 다음 단계

Scenario Dreamer는 생성 모델이라 mining에는 직접 쓰기 어렵습니다. 생성과 mining을 어떻게 연결할지 정의가 필요합니다.
