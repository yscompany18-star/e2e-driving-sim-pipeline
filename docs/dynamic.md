# Dynamic Scene

## 정의

차량, 보행자, 자전거 등 움직이는 객체를 개별 자산으로 복원해 궤적을 바꿀 수 있게 합니다.

## 왜 필요한가

반응형 시뮬레이션과 장면 편집은 객체가 분리되어 있어야만 가능합니다.

## 접근 방법

3D 박스 트랙으로 객체별 Gaussian을 학습하고, 포즈를 함께 보정합니다. 보행자 같은 비강체는 OmniRe처럼 변형 모델을 씁니다.

## 평가 방법

객체 영역 PSNR, 궤적 변경 시 외관 일관성, 포즈 보정 전후 차이.

## 오픈 이슈 · 다음 단계

트래킹 노이즈와 가림이 큰 객체는 반대편 외관이 비어 있어 회전·재배치 시 품질이 떨어집니다.
