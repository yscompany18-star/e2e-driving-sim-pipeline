# Sim-to-Real gap 최소화

## 정의

시뮬 평가 결과(순위·지표)가 실차 결과와 일치하도록 만드는 것이 이 세션의 최종 목표입니다.

## 왜 필요한가

시뮬 점수가 실차를 예측하지 못하면 시뮬레이션 투자가 의사결정에 쓰일 수 없습니다.

## 접근 방법

센서 시뮬레이터 교체 시 정책 순위 보존 확인(OmniDreams), pseudo-simulation 상관 분석(R²), 생성 모델로 외관 차이 보정(Cosmos-Transfer).

## 평가 방법

실차 소수 장면 대비 순위 상관(Spearman), 지표 상관(R²).

## 오픈 이슈 · 다음 단계

실차 비교용 장면을 어떻게 확보하고 얼마나 필요한지 기준이 없습니다.
