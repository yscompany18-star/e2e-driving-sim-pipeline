# Simulation Speed

## 정의

대규모 시나리오를 평가할 수 있는 처리량(FPS, 장면당 시간, GPU 비용).

## 왜 필요한가

의미 있는 통계를 내려면 수백~수천 장면을 반복 평가해야 합니다.

## 접근 방법

3DGS rasterization 기반 렌더러, 장면 압축, 병렬 장면 실행, 생성형 센서 시뮬레이터의 실시간화(OmniDreams).

## 평가 방법

장면당 wall-clock 시간, 정책 추론을 제외한 렌더링 FPS, GPU당 동시 장면 수.

## 오픈 이슈 · 다음 단계

fixer나 생성 모델을 추가할수록 품질은 오르고 속도는 떨어집니다. 예산 기준이 필요합니다.
